목표
그래프를 기본 작업 공간으로 삼고, 번역 AI가 읽은 문맥과 만들어 낸 변경을 추적한다.
장면 상세는 그래프에서 들어가는 순서형 대사 편집 화면이다.

탐색과 화면
- 브랜드 상단바 제거. 프로젝트 선택과 주요 메뉴를 한 줄에 배치한다.
- 작업 상태는 작은 버튼으로 표시한다. 진행 상세·일시정지·취소는 팝업에서 연다.
- 완료 상태는 일시 알림과 실행 기록에 남기며 상시 바를 차지하지 않는다.
- 장면 지도 / 작품 전체 대사 / 선택 장면 대사 / 주변 노드를 명확히 구분한다.
- 큰 그래프는 표시 범위·전체 개수·페이지·검색·초점 이동을 제공한다.
- 실제 그래프에 없는 간선은 만들지 않는다. 연결되지 않은 원문도 접근 가능해야 한다.
- 원문·번역·화자·ID·용어로 검색하고 해당 노드 또는 순서형 대사로 이동한다.
- 오른쪽 상세 패널은 캔버스 위에 떠 있으며 닫기·접기·너비 조절이 가능하다.
- 미니맵은 왼쪽 위에 배치하며 접을 수 있다.

노드 의미
- unitIds를 가진 실제 원문 노드: 사각 카드, 화자·본문·번역 상태.
- 조건: 마름모. 대기·상태: 작은 캡슐. 연결·합류: 작은 점.
- 원문과 조건이 함께 있으면 원문 카드에 조건 배지.
- 제어 노드는 번역량과 완료율에 포함하지 않는다.

실행 설정과 검증
- 사용자 최신 분류: AI 설정은 '연결'과 '작업' 두 탭으로 나눈다. 연결 탭은 계정·엔드포인트를 관리하고, 작업 탭은 선택한 작업의 연결·모델·추론 수준·지시문·문맥·시험을 한곳에 모은다.
- 작업별 연결·모델·추론 수준 외에 지시문과 문맥 포함 정책을 설정한다.
- 실제 조립된 프롬프트·문맥·응답 스키마를 실행 전 미리 본다.
- 소량 시험 결과는 별도 보관하며 번역 본문에 자동 반영하지 않는다.
- 요청/응답 모델·추론 수준, 시간·사용량·검증 결과를 표시한다.
- 모델 기능은 확인됨/지원 안 함/미확인을 구분하고 실행도 같은 규칙으로 검사한다.
- Claude Code CLI 연결·로그인·상태·비대화식 구조화 실행을 추가한다.

자료와 변경 이력
- 작품 자료: 줄거리·인물/관계/말투·사실·규칙, 분기·공개 범위·근거.
- 자료 버전·생성 실행·이전 자료를 보존한다.
- 편집·복원은 새 버전으로 기록하고 사용한 번역은 재검토 대상으로 올린다.
- 노드별 번역 전후, 용어 등록/변경, 자료 변화, 검수 결과, 수동 변경, 재검토 이유를 확인한다.
- 실행 단계·모델·프롬프트 버전·실제 문맥 스냅샷을 연결한다.
- 기록되지 않은 과거 정보는 만들지 않는다. 기존 번역 이력은 계속 보여 준다.

데모와 보존
- 별도 저장 공간에 3장면·24원문 가상 데모를 만든다.
- 브리핑 → 선택 기록실 → 보고, 바로 보고하는 경로 및 증언 분기를 포함한다.
- 기존 Orwell 번역·실행·설정은 데모 전환 시 보존한다.
- 원본 게임 및 다른 Orwell 패치·추출 폴더는 수정하지 않는다.

검증 기준
- 기존 저장 자료 호환 및 원문·번역 보존 비교.
- 제어/번역 노드 분리, 범위·검색·분기·미연결 원문 접근 검사.
- 모의 실행으로 요청 → 문맥 → 응답 검사 → 변경/자료 이력 → UI 연결 검증.
- 시험 실행의 번역 비변경, 자료 변경 재검토 전파 검사.
- 가짜 CLI 테스트, 타입 검사, 빌드, 브라우저 사용 흐름 검증.
- 실제 유료 호출과 CLI 로그인 검증 여부를 구분해서 보고한다.

현재 구현 범위와 한계
- Core는 단계별 추가 지시문·버전과 용어집/작품 자료/앞선 번역의 포함 정책, 별도 시험 기록, 실행 입력 스냅샷, 자료 버전·복원 및 변경 이력을 지원한다.
- 명시적인 branch는 대상 원문별로 문맥을 분리한다. 같은 장면 안에 여러 branch가 있어도 지식과 앞선 번역의 적용 대상 원문 ID를 구분하며, 공통 합류에 다른 분기의 번역 기억을 섞지 않는다.
- 조건의 원본 값과 연결은 보존한다. 의미가 해석되지 않은 조건(opaque condition)을 실제 게임처럼 평가하지 않으며, 조건 충족·실제 실행 경로·인물의 인지 여부를 그래프 배치만으로 확정하지 않는다.
- 번역자용 전체 작품 참고 자료는 인물의 기억과 구분한다. 조건에 따른 정확한 공개 시점은 게임별 근거와 별도 검토가 필요하다.
