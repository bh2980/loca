Translation Workbench v0.2 구현·검증 현황
기준: DEVELOPMENT_PLAN_V2.txt / UX_FLOW_PLAN.txt
갱신: 2026-10-09 (Asia/Seoul)

이 파일은 현재 구현과 실제 확인 범위를 구분한다. 계획서의 목표를 완료된
항목만으로 축소하지 않는다. 타입/빌드/모의 시험은 실제 AI 품질이나 전체 UX를
보증하지 않으며 확인한 범위와 미지원/미검증 항목을 따로 기록한다.

M0 — 계약·데이터 보존·승인 경계: 구현, 자동 검사 통과
  Studio/Workflow sidecar 계약과 구버전 마이그레이션을 추가했다.
  고정 Stage 프로필을 ID/버전이 있는 이름 있는 프로필로 복사하고, checked를
  사람이 승인했다는 이력으로 꾸미지 않는다. 원문·번역·수정 이력·잠금·출처·
  용어 사용 정보를 보존하며 과거 번역과 현재 대표를 후보로 보관한다.
  변경 제안 수락과 직접 사용자 편집, 사용자가 시작한 프로세스 자동 반영을 구별한다.
  프로젝트/세션/원문 참조·기준 버전·잠금을 검사하고 제안 전체를 원자적으로 적용한다.
  수락은 멱등이며 미승인/거절/피드백/초안 편집은 프로젝트 본문을 바꾸지 않는다.
  저장/복원 경계에서 프로세스 그래프·스냅샷·대상/실행 참조·백업 저널을 검증한다.
  손상된 저장 기록의 부분 복원이나 불확실한 호출의 무음 재개를 막는다.
  증거: packages/core/tests/studio.test.ts, workflow.test.ts,
        core 프로젝트/가져오기 검사, apps/worker/tests/workflow-backup.test.ts.

M1 — 원문 그래프 통일: 기능 구현·실규모 탐색과 전체 축척 드래그 실측 확인
  React Flow 구현/의존성/전용 CSS를 제거했다. 장면·대사 그래프는 D3 + Canvas를
  사용하며 인물·프로세스도 Canvas 상호작용을 사용한다.
  원본 노드·간선/조건·미확인 참조와 장면 축약의 근거를 유지한다.
  의미 형태, 방향 배치, 미니맵, 검색/선택/상세, Back/Forward·새로고침 복원을 제공한다.
  전체 대사 범위를 임의 120/600개로 자르지 않는다. 검색 결과 페이지와 사용자가
  고른 주변 범위는 별도이며 총수/표시 범위를 밝힌다.
  임시 Orwell 1 복사본에서 전체 그래프 9,815노드/5,932간선 일치, 검색 마지막
  페이지 → 연결 없는 원문 선택 → Back 범위/페이지/확대·이동 복원을 확인했다.
  원본 아티팩트 해시가 import 전후 동일했다.
  전체 축척 비트맵 준비 CPU 39.3ms, 가장 긴 분할 4.2ms, draw 5.0ms를 기록했다.
  실제 포인터 드래그 20회/149 rAF 표본에서 중앙 18.0ms, p95 18.2ms,
  최대 18.3ms와 마지막 draw 1.4ms를 확인했다. 읽기 배율의 실제 원문 클릭도 확인했다.
  해당 브라우저·크기·배율의 결과이며 draw 시간은 FPS가 아니다. 물리적 화면 제시
  지연, 모든 배율/기기의 프레임·선택 지연을 측정했다고 주장하지 않는다.
  증거: artifacts/v2-browser-verification.txt, scene-projection/graph/navigation 검사.

M2 — 프로젝트 채팅·자료·인물/관계: 기능 구현, 모의 통합 여정 확인
  프로젝트별 세션·새 세션·이름/첨부/입력 초안·기록 페이지 조회를 제공한다.
  원문·자료·용어·인물/관계·실행/상태·변경 이력 읽기 도구는 실제 저장 상태를
  조회하며 총수/페이지/기준 버전을 반환한다. 승인 대기 초안은 번역 문맥에서 제외한다.
  웹 ON/OFF와 SearXNG 검색/페이지 읽기, 출처·근거 기록, 도구/검색/토큰 한도와
  중지를 구현했다. OFF는 서버에서도 새 외부 요청을 차단한다.
  OpenAI 호환 Chat Completions/Responses만 채팅 도구 호출 어댑터를 지원한다.
  Codex/Grok/Antigravity/Claude CLI, System One과 mock 연결 종류는 채팅 미지원이다.
  capability는 어댑터 지원을 뜻하며 실제 서버/모델의 인증·도구 지원을 증명하지 않는다.
  조사 → 초안 → 수락 → 작품 자료·인물/관계 Canvas → 원문 근거 → Back/Reload
  여정을 임시 DB/모의 OpenAI 호환 HTTP에서 확인했다.
  피드백·초안 직접 편집·거절·중복 수락·오래된 기준·타 프로젝트·웹 OFF 차단은
  자동 테스트로 확인했다. 모든 조합을 브라우저에서 확인했다고 주장하지 않는다.
  SSE 부분 응답 표시·저장·중지와 도구 인자 조립을 구현하고 모의 통합/브라우저에서 확인했다.
  새 세션의 부분 응답 "원문을" → 중지 → 중단된 응답 보존 → 후속 메시지의 부분 응답
  → 원문 조회·초안 생성 → 수락 대기 v1 완료를 확인했다. 실제 모델 추론 시험은 아니다.
  프로필 복제·JSON 내보내기 → 새 초안으로 가져오기 → 이름 변경·저장 → 재로드를
  브라우저에서 확인했다. 기존 프로필·연결과 미저장 복제 초안을 보존했다.
  증거: packages/core/tests/studio.test.ts, apps/worker/tests/project-chat.test.ts,
        packages/providers/tests/chat*.test.ts, artifacts/v2-browser-verification.txt.

M3 — 사용자 정의 실행기·대사별 분기·후보: 구현, 모의/저장 실행 확인
  저장 정의·포트·간선을 실행기가 해석한다. 정의/프로필/도구 연결/대상을 실행
  시작 시 고정하며 고정 Stage의 별도 순서를 화면의 선처럼 표시하지 않는다.
  시작/조회/묶음/AI/조건/프로젝트 행동/사람/종료 노드를 실행한다.
  30개 번역·검수에서 27개 통과/3개만 수정 묶음으로 재집결하는 검사를 통과했다.
  대사/묶음 모두/하나 이상 조건, 완료한 수정 라운드와 provider retry/fallback의
  분리, 세 번 수정 후 사람 대기, 동료 대상 계속 진행을 확인했다.
  대상 밖·누락/중복 ID·잠금·버전 충돌·보호 토큰 손상은 검증하며 변경을 추측하지 않는다.
  후보 보관과 대표 선택을 구별하고 확정은 실제 현재 번역의 QA/용어 조건을 검사한다.
  사람 편집/수락·거절·보류, 일시정지·취소·재시작/명시적 재개를 영속화한다.
  단위 상세의 후보·진행에서 직접 상태/라벨 생성·부여와 대표 후보 선택을 제공한다.
  장면/선택 ID/전체 범위에 상태 OR·라벨 AND 필터를 함께 적용한다.
  대상 수/미리보기/시험/실행은 같은 ID 집합이며 잘못된 참조와 0개 시작을 막는다.
  브라우저에서 초안 상태 + 근거확인됨 라벨로 relay-01만 1/8개를 선택하고
  모의 시험이 원문 1개만 처리·완료하는 것을 확인했다.
  사용자 정의 WorkflowRunner는 한 번에 한 모델/외부 호출을 진행한다.
  연결별 독립 분기 병렬 동시 실행은 아직 지원하지 않으며 제한으로 남긴다.
  증거: packages/core/tests/workflow.test.ts, studio.test.ts,
        artifacts/v2-browser-verification.txt.

M4 — 프로세스 편집과 실제 실행/추적: 구현, 주요 브라우저 여정 확인
  D3 + Canvas 노드 추가/이동/포트 연결, 오른쪽 설정, 입력 매핑,
  field/operator/value와 AND/OR 조건 폼, 고급 JSON을 제공한다.
  준비/정상 번역/확정/수정·사람 확인의 초기 배치를 구별하고 저장 좌표를 유지한다.
  전체 맞춤·흐름 정리와 오류 경로 표시 선택, 미저장 초안/선택/viewport 보존을 제공한다.
  검사/저장 정의와 실행 경로를 연결하며 모의 시험은 복사본에서만 수행한다.
  대사별 위치·수정 횟수와 노드 입력/출력/시도/변경 기록을 확인할 수 있다.
  실행 흐름 vN/편집 흐름 vN을 전환한다. 과거 실행은 당시 정의의 읽기 전용 그래프이며
  편집 초안/선택/viewport를 별도로 보존한다. 실제 실행 v2 ↔ 편집 v4 전환을 확인했다.
  모의 흐름은 "시험한 초안"으로 표시하며 복사본 버전을 저장 정의의 버전처럼 표시하지 않는다.
  읽기 전용 화면에는 현재 편집 필터 대신 해당 실행의 고정 대상 수를 표시한다.
  실제 브라우저에서 템플릿 v1 실행과 data.passed == false 조건의 v2 실행 결과가
  달라지는 것을 확인했다. 단일 대상 사람 수락 후 다른 7개 대기가 유지됐다.
  root 후속 브라우저 확인: 높이/테마/조건 폼 정상, relay-01 처리와 나머지 대기가
  서버 재시작 뒤 보존됐다. 알림은 레이아웃 공간을 차지하지 않는 닫을 수 있는 토스트다.
  실제 포트 드래그로 거짓 출구를 사람 확인에 연결하고 좌표 이동/저장/재로드를 확인했다. 모든 브라우저 조합은 미검증이다. source handler 검토로
  저배율 첫 포트 오선택·과도한 hit 영역·포인터 capture 종료 처리를 고쳤고
  nearest-port/좌표 보존/전체 맞춤은 독립 테스트로 검사했다.
  증거: artifacts/v2-browser-verification.txt, scripts/workflow-layout.test.ts.

M5 — HTTP 요청/응답·100개 백업: 구현, 로컬 모의/API·파일 검사 통과
  공개 도구 연결과 별도 암호화 인증, GET/POST, query/body 필드 참조/상수,
  응답 경로, 개별/묶음 원문 ID 대응, timeout/크기/시도 한도를 구현했다.
  저장/검사/실행 시작 시 HTTP/백업 설정을 검증하고 연결 URL을 실행에 고정한다.
  HTTP 결과는 해당 대상의 출력이며 적용 행동 전에는 번역 본문에 반영하지 않는다.
  누락/중복/범위 밖 응답 ID, 429/일시 오류, 잘못된 JSON, 리디렉션, 인증 노출과
  취소/timeout을 로컬 합성 HTTP에서 검사했다. 실제 유료 사전·맞춤법은 미검증이다.
  백업은 서로 다른 대표 저장 또는 확정 unitId를 집계하고 95→112, 여러 임계값,
  중복 저장, 파일 실패/pending 복구, 종료 잔여분과 복원의 revision/집계를 검사했다.
  spool → pending DB 기록 → digest 확인·파일 확정 → 카운터 commit 순서를 사용한다.
  채팅/제안/후보/자료/인물·관계/정의·실행 위치/백업 진행을 포함한다.
  비밀값과 AI endpoint 정의는 제외하며 복원만으로 AI/외부 행동을 시작하지 않는다.
  현재 DB 재시작과 백업 파일 복원은 구별한다. 백업의 남은 AI 작업은 현재 연결을
  다시 설정하고 새 실행으로 시작해야 할 수 있다.
  증거: apps/worker/tests/workflow-http.test.ts, workflow-backup.test.ts,
        tool/API/credential 검사. 브라우저에서는 공개 도구 연결 저장을 확인했다.
