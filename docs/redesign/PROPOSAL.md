## 0. 요약 (결론 먼저)

#48은 **다듬기**였다. 글자 단계, 대비, 메뉴 이름은 정리됐지만 화면의 **골격**은 그대로다. 그래서 같은 줄에 성격이 다른 것들이 계속 섞인다. 화면 이동, 보기 전환, 필터, 상태 문구, 주 동작, 전역 토글이 한 줄에 같이 있다. 오른쪽에는 속성 패널과 채팅이 서로 자리를 다툰다.

impeccable 기준으로 이번 작업은 "Refinement preserves; redesign replaces"의 **redesign**이다. 지금 배치는 버릴 기준(anti-reference)으로 보고, DESIGN.md §4(정보 구조)를 새로 쓴다. 다만 시각 토큰(Pretendard, 절제된 색, 4px 모서리, 1px 선)은 제품의 사실로 유지한다. 주인이 불만을 말한 곳은 구조이지 색이나 글꼴이 아니다. 화면 모드는 Operate다. 익숙한 패턴, 훑어보기 쉬움, 일관성이 표현력보다 먼저다.

**구조 변경 Top 5**

1. **오른쪽 도크 하나.** 오른쪽 가장자리에 도크를 하나만 두고 그 안에 `속성 | 에이전트` 탭을 둔다. 지금은 상세 패널, 대사 패널, 채팅이 각자 열려서 본문을 세 번 좁힌다. 넓은 화면(≥1600px)에서만 둘을 나란히 고정할 수 있게 한다. 토글은 상단 바 맨 오른쪽에 고정한다(HIG: 인스펙터 토글은 trailing-most이고 움직이지 않는다).
2. **툴바 3층 규칙.** 모든 화면은 아래 세 층만 쓴다.
   - ① 페이지 머리: 제목, 보기 전환, 주 동작 1개, ⋯(더보기)
   - ② 필터 막대: 검색, 필터, 걸린 필터 칩, 개수
   - ③ 문맥 막대: 선택 막대 또는 캔버스 위 선택 도구상자

   상태 문구("마지막 분석 …, 초안 15개 …")는 어떤 툴바에도 넣지 않는다. 인스펙터의 '선택 없음' 상태나 아래 상태 막대로 보낸다. 세그먼트(보기 전환)와 동작 버튼은 같은 그룹에 두지 않는다(Primer ActionBar).
3. **인스펙터 표준 골격.** 순서는 머리(종류, 이름, 상태 칩, ⋯) → 접히는 섹션 → '고급'은 기본 접힘 → 수정했을 때만 나타나는 저장 막대다. 삭제는 ⋯ 메뉴 안이나 맨 아래 위험 구역에만 둔다. 섹션 분류 기준은 한 가지만 쓴다. Retool은 40개였던 섹션을 Content / Interaction / Appearance 3개로 줄였다. 인물, 용어, 연결, 노드, 대사가 모두 같은 `Inspector` 부품을 쓴다.
4. **내비게이션 한 층.** 지금은 메뉴가 두 층으로 나뉘어 있다. 왼쪽 사이드바가 대분류이고, 상단 밑줄 탭이 하위 화면이다. 이것을 Linear처럼 **사이드바 그룹 + 하위 항목**으로 합친다. 상단 바는 페이지 머리(①)로 돌려준다. AI 관련 설정이 AI, 에이전트, 워크플로 › API 키 세 곳에 흩어져 있는 것도 **설정 한 화면**(왼쪽 섹션 목록)으로 모은다.
5. **캔버스 화면 공통 틀.** 대사 그래프, 인물·관계, 사건 흐름, 워크플로 편집기가 모두 같은 틀을 쓴다.
   - 왼쪽: 접히는 목록(구역, 노드 라이브러리)
   - 가운데: 캔버스와 하단 떠 있는 캔버스 도구(줌, 맞춤, 정렬, 미니맵, 범례)
   - 오른쪽: 선택을 따라가는 인스펙터(articy synced pane, ComfyUI right side panel)

   워크플로 노드 설정은 캔버스를 덮지 않는다. 도크에 붙어서 열린다.

## 2. 영역별 채택할 패턴

### 2.1 앱 셸과 내비게이션
- **뒤집은 L 크롬**(Linear): 왼쪽 사이드바와 위쪽 페이지 머리만 앱 크롬이다. 본문 안에 크롬을 하나 더 만들지 않는다.
- **사이드바 = 유일한 탐색.** 그룹 머리 아래에 하위 화면을 둔다(접힘 가능, 그룹은 구분선). 상단 '섹션 탭'은 없앤다. 한 화면 안에서 같은 데이터를 바꿔 보는 것(그래프/표)은 탐색이 아니라 **보기 전환**이므로 페이지 머리의 세그먼트로 둔다.
- **토글 고정**(HIG): 사이드바 토글은 맨 왼쪽, 오른쪽 도크 토글은 맨 오른쪽에 둔다. 전역 검색(⌘K)은 그 바로 왼쪽이다. 페이지 동작은 그 사이에 두고, 전역 항목과는 구분선으로 나눈다.
- **오른쪽 도크 하나**: `속성 | 에이전트` 탭. 도크 폭은 화면마다 기억한다(지금 규칙 유지). 빨간 점과 개수 배지는 토글 아이콘에만 붙인다(ComfyUI의 오류 점).
- **상태 막대**(memoQ, HIG bottom bar): 진행률, 선택 개수, 저장 상태, 실행 중인 작업, 단축키 힌트를 본문 아래 24px 줄에 둔다. 지금 툴바에 끼어 있는 상태 문구를 이리로 옮긴다.

### 2.2 편집기 레이아웃 (목록 · 상세 · 인스펙터)
- **3분할 고정**(Phrase/Lokalise/memoQ): 탐색(장면 트리, 접힘) / 격자(원문 | 번역) / 인스펙터(문맥 사이드바).
- **셀 안은 글만** 둔다. 행 동작은 hover나 focus 때만 보이는 미니 도구(Crowdin)로 처리한다. 확정은 `Ctrl+Enter`로 하고 다음 줄로 넘어간다(memoQ). 초안은 자동 저장한다. '저장' 버튼은 지운다(DESIGN의 초안 보관 규칙과 같다).
- **인스펙터 섹션은 선택에 따라 바뀐다**(Phrase). 대사를 고르면 `문맥(화자→청자·장면·앞뒤 줄) · 후보·AI 제안 · 검사 · 용어 · 이력`이 나온다. 내용 없는 섹션은 숨긴다. 섹션 순서와 표시 여부는 사용자가 정한다.
- **보기 모드**(Crowdin): `격자`(기본) / `집중`(한 줄, Weblate Zen) / `검토`(원문·번역 문서 미리보기, Crowdin Dual Preview). 같은 데이터, 같은 URL 파라미터 `display`로 바꾼다.

### 2.3 툴바 위계
| 층 | 위치 | 내용 | 규칙 |
|---|---|---|---|
| ① 페이지 머리 | 상단 바(사이드바 토글 오른쪽) | 페이지 제목(+브레드크럼), **보기 전환 세그먼트**, 주 동작 1개, ⋯ 더보기 | 주 동작은 화면마다 **딱 1개**다(검정). 나머지는 ⋯에 넣는다. 세그먼트와 동작 사이에는 구분선을 둔다 |
| ② 필터 막대 | 본문 맨 위 1줄(accessory bar) | 검색 → 필터 → 걸린 필터 칩 → (오른쪽) 개수, 정렬, 표시 옵션 | 동작 버튼은 넣지 않는다. 줄바꿈하지 않는다(Fluent) |
| ③ 문맥 막대 | 선택이 생기면 ②를 대신하는 막대 / 캔버스는 선택 위에 뜨는 도구상자 | `n개 선택 · 동작들 · 해제` | 고른 것에만 적용된다(HIG accessory). 지금의 `PickedBar`를 확장한다 |
| 캔버스 도구 | 캔버스 아래 떠 있는 막대 | 줌, 맞춤, 자동 정렬, 미니맵, 범례 | Figma·Arcweave·ComfyUI와 같다. 위쪽을 비운다 |
| 상태 막대 | 본문 아래 | 진행, 저장 상태, 작업 | 버튼은 넣지 않는다(링크는 가능) |

넘침 규칙: 항목마다 우선순위를 둔다. 폭이 모자라면 낮은 것부터 ⋯로 보낸다(HIG visibilityPriority, Fluent overflow). ⋯ 메뉴 안에서는 아이콘 + 글자로 보인다. 파괴 동작은 메뉴 맨 아래에 구분선을 두고 넣는다.

### 2.4 속성 인스펙터 구조
```
┌ 인스펙터 머리 ─────────────────────────┐
│ 종류 · 이름                    [상태칩] ⋯ ×│  ← ⋯: 복제·링크 복사·삭제(맨 아래)
│ 사실 한 줄 (예: 대사 7 · 관계 2)          │
├ [섹션 앵커: 기본 · 번역 지시 · 근거 · 고급] ┤  ← 길면(Phrase식 점프)
│ ▾ 기본           (자주 쓰는 것, 항상 펼침)  │
│ ▾ 번역에 들어가는 것                       │
│ ▸ 근거·이력      (기본 접힘)               │
│ ▸ 고급           (기본 접힘, Retool)       │
│   + 속성 추가    (선택 항목은 꺼내 쓰기)    │
├─────────────────────────────────────────┤
│ (수정했을 때만) 바뀐 곳 3 · [되돌리기] [저장] │  ← 고정 막대
└─────────────────────────────────────────┘
```
- 분류 기준은 **하나**만 쓴다: '번역에 무엇으로 쓰이나'(기본 / 번역 지시 / 근거 / 고급). 한 섹션 안에서만 기본·고급으로 다시 나눈다(Retool의 '차례로 적용').
- **라벨-값 한 줄**(Linear 속성 패널): 짧은 값(성별·나이·비중·출처)은 `라벨 | 값` 두 칸 격자에 둔다. 긴 글(프로필·지시문)만 전체 폭으로 쓴다.
- **선택 없음 = 개요**(ComfyUI 'Workflow Overview', Rive 'file settings'): 그 화면의 요약, 마지막 분석, 범례, 즐겨찾기 속성.
- **여러 개 선택 = 공통 속성만**: 일괄로 바꿀 수 있는 것만 보인다.
- 저장/삭제를 나란히 두지 않는다. 삭제는 ⋯ 안이나 맨 아래 위험 구역에 두고 AlertDialog를 거친다(지금 규칙 유지).

### 2.5 그래프 보기
- **동기화 인스펙터**(articy): 노드를 누르면 도크의 `속성` 탭이 그 노드를 보인다. 그래프에서 Alt+화살표로 옆 노드, Enter로 번역 카드.
- **노드가 상태를 말한다**: 장면 노드에 상태 색 진행 막대(번역/전체)를 넣는다. 인물 노드는 비중(주연·조연·단역)에 따라 크기와 굵기를 바꾸고 아바타 머리띠를 단다(Arcweave). 관계 선 라벨은 고르거나 가리킬 때만 전체를 보이고, 평소에는 알약 하나(Arcweave 선택지 라벨)로 둔다.
- **범례와 캔버스 도구는 떠 있게**: 아래 왼쪽에 범례와 미니맵 토글, 아래 오른쪽에 줌, 맞춤, 정렬, 배치 되돌리기.
- **노드 찾기**는 ② 필터 막대에 둔다(캔버스 위에 떠 있는 검색 상자를 없앤다).

### 2.6 워크플로 노드 편집기
- 왼쪽: **노드 라이브러리**(검색, 범주별: AI·검사·분기·상태; 끌어 놓기, ComfyUI). 지금의 '+ 노드 추가' 버튼을 대신한다.
- 가운데: 캔버스. 노드는 작게(제목, 모델 한 줄, 경고 점). 선택하면 노드 위에 도구상자(복제·비활성·삭제)가 뜬다.
- 오른쪽: 도크 `속성`. 탭은 `설정 | 입출력 | 오류`(ComfyUI). 설정 섹션은 `기본(이름·모델) · 지시문 · 출력 · 고급(온도·함께 나눌 모델·시간 제한)`이다. 지시문 편집은 **'크게 열기'**로 n8n NDV식 3열 모달(앞 노드 출력 예시 | 지시문 | 이 노드 출력 예시)을 연다.
- 페이지 머리: `← 워크플로 / 기본 번역 v3 · 저장됨 10:58` · 주 동작 `▷ 실행`(split: 범위 고르기) · ⋯(복제·내보내기·삭제). '저장'은 자동 저장 표시로 바꾸고, '자동 정렬'은 캔버스 도구로 옮긴다.

### 2.7 채팅 패널
- 도크의 `에이전트` 탭이다. 폭이 좁으면 `속성` 탭과 번갈아 쓰고, 넓으면 둘을 나란히 고정한다.
- **도구 호출은 한 줄로 접는다**: `✓ 용어 9개 추가 · 펼치기`. 지금처럼 MockTerm 목록을 모두 펼쳐 두지 않는다(Cursor).
- **검토 막대**를 입력창 위에 고정한다: `제안 3 · 모두 수락 · 모두 거절 · 되돌리기`(Cursor Keep/Undo All). 우회 모드에서는 '되돌리기'만 둔다.
- **자동 문맥 칩**(Notion): 지금 보고 있는 화면, 고른 줄을 칩으로 자동으로 넣는다. @로 더 붙인다.
- 입력창 아래 한 줄: `모델 선택 · 권한 모드 · (오른쪽) 보내기`. 지금 구조를 유지하고, 모드에 색 점을 붙인다.

### 2.8 설정
- **설정 한 화면**(HIG Preference, Linear Settings): 왼쪽 섹션 목록에 `프로젝트 · 상태·태그 · 형식 규칙 · AI 연결 · 편집기 AI(사용 방식) · 에이전트 권한 · API 키 · 위험 구역`.
- 목록형 설정(연결, API 키, 상태)은 **표 + 오른쪽 인스펙터**로 한다. 인스펙터는 2.4 골격을 따른다. 연결 시험은 인스펙터의 `시험` 섹션에 둔다.
- 폼형 설정은 지금의 `SettingsSection`(스위치는 즉시 저장, 입력은 저장 막대)을 유지하고, **페이지 아래 저장 막대 하나**로 합친다.

## 5. 단계별 구현 계획 (`@loca/ui`)

원칙은 네 가지다.
- 부품을 먼저 만들고 화면을 나중에 옮긴다.
- 화면 하나는 PR 하나다.
- PR마다 1280과 1500에서 개선 전후 스크린숏을 남긴다(`/workspace/loca-review/redesign/<phase>/`).
- 기능과 URL 파라미터는 바꾸지 않는다(DESIGN §5 규칙 유지).

**P0. 결정과 문서 (코드 없음)**
- DESIGN.md §4를 이 문서의 4.1~4.11로 **교체**한다(덧대지 않는다). §4.1 부품 표를 갱신하고, `HeaderActions` 예외를 없앤다.
- 정해야 할 것:
  - 용어집 위치(번역 아래 유지 / 자료로)
  - 도크 기본(탭 / 나란히)
  - 집중·검토 보기를 이번 범위에 넣을지

**P1. 셸 부품** (`packages/ui/src/layout/`)
- `AppShell`: 사이드바 + 페이지 머리 + 본문 + 상태 막대 + 도크
- `SidebarNav`: 그룹, 하위 항목, 접힘
- `PageHeader`: 제목·브레드크럼, `ViewSwitch` 슬롯, 주 동작 1개, `OverflowMenu`
- `RightDock`: 탭(속성·에이전트), 폭 기억, 배지와 점
- `StatusBar`

화면 적용은 상단 섹션 탭을 사이드바 하위 항목으로 옮기고, 채팅과 상세 패널을 도크로 합치는 것이다. `ui-rules`에는 '페이지당 primary 1개'와 '툴바 안 SegmentedControl 금지' 검사를 넣는다.

**P2. 툴바 부품** (`packages/ui/src/data/`, `layout/`)
- `FilterBar`: 검색, 필터, 칩, 개수. 기존 `Toolbar`, `FilterChips`, `SearchInput`을 합친다
- `ActionBar`: 우선순위 기반 넘침, ⋯ 메뉴, 파괴 동작 분리, `role=toolbar`
- `SelectionBar`: 기존 `PickedBar` 확장

**P3. 인스펙터 부품** (`packages/ui/src/inspector/`, 새 폴더)
- `Inspector`, `InspectorHeader`(종류·이름·상태칩·⋯·닫기)
- `InspectorTabs`(필요할 때만), `InspectorSection`(접힘, 앵커)
- `PropertyGrid`·`PropertyRow`(라벨-값 2칸), `AdvancedDisclosure`, `AddPropertyList`
- `DirtyBar`(바뀐 곳 n · 되돌리기 · 저장), `DangerZone`, `EmptySelection`(개요 슬롯)

기존 `DetailPane`은 이것으로 대체한다. 옮기는 순서는 인물 → 용어 → AI 연결 → 워크플로 노드 → 실행 → 대사다.

**P4. 편집기**
- 대사 격자 셀에서 아이콘과 버튼을 걷어내고, 포커스한 줄의 미니 동작, `⌘↵ 확정·다음`, 자동 저장으로 바꾼다.
- 장면 트리와 저장된 보기를 분리한다.
- 대사 인스펙터 섹션을 만든다: 문맥 · 후보·AI 제안 · 검사 · 용어 · 이력. 기존 `line-detail.tsx` 334줄을 섹션 부품으로 나눈다.
- (선택) 집중 보기를 만든다.

**P5. 캔버스 공통**
- `packages/ui/src/canvas/`에 `CanvasToolbar`(줌·맞춤·정렬·미니맵), `Legend`, `SelectionToolbox`, `NodeCard`(머리띠·진행 막대·아바타 슬롯)를 만든다.
- 대사 그래프, 인물·관계, 사건 흐름, 워크플로에 적용한다.
- 워크플로는 노드 라이브러리 패널을 만들고, 노드 설정을 도크로 옮긴다(오버레이 제거). 지시문은 NDV 모달로 연다.

**P6. 채팅 도크**
- 도구 호출을 한 줄로 접는다.
- 검토 막대(모두 수락·거절·되돌리기)를 만든다. 되돌리기 API는 진행 중인 작업과 맞춘다.
- 자동 문맥 칩을 넣는다.

**P7. 설정 통합과 홈**
- `/settings/:section` 한 화면으로 합친다. AI › 연결, 사용 방식, 에이전트, API 키 경로는 옮기고, 옛 경로는 리디렉트한다(DESIGN의 '별칭을 두지 않는다' 규칙과 충돌하므로 P0에서 결정한다).
- 홈의 'AI가 정함' 행들을 하나로 합친다.

**P8. 검증**
- impeccable `audit`와 `critique`를 1280, 1500, 1920에서 돌린다.
- 채팅과 도크를 열었을 때 원문·번역 칸이 각각 320px 이상인지 잰다.
- 키보드만으로 편집기를 쓸 수 있는지 확인한다(확정, 다음 줄, 도크 토글, ⌘K).
- 이 문서의 V1~V15를 하나씩 확인한다.

예상 규모: P1~P3이 부품 PR 6~8개, P4~P7이 화면 PR 10~14개다. P1(셸)과 P3(인스펙터)이 나머지를 막고 있으니 먼저 한다.
