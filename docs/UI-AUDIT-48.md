# UI 감사와 계획 (#48)

impeccable 스킬(`audit`, `typeset`, `layout`, `operate`, craft floor)로 화면을 점검했다. 대상은 앱 화면(Operate 모드)이다. 기존 시각 체계(Pretendard, 표면 단계, 남보라 강조, 잔선)는 유지하는 다듬기이고, 새 디자인으로 바꾸는 것이 아니다. 같은 기준을 화면마다 지키고 정보 구조를 정리하는 것이 목표다.

- 측정 환경: Linux, Chrome(headless), 1280×800과 1500×900, 예시 프로젝트 '중계소'
- 개선 전 스크린숏: `/workspace/loca-review/batch5/before/`
- 글자 크기 측정값: `before/font-sizes.txt`

| 용어집 | 93% | |

본문 역할(표의 행, 채팅 답, 설정 설명)이 거의 모두 `text-xs`(12px)이다. 코드 전체에서 `text-xs`는 419번, `text-sm`은 179번 쓰였다. 위계가 크기가 아니라 회색 정도로만 표현돼서 "작고 빽빽하다"는 인상을 준다.

## 문제 목록 (심각도순)

**P1**
1. **글자 단계와 본문 크기.** 본문이 12px이고, 배지·칩은 10–11px까지 내려간다. 모든 글자에 음수 자간(-0.011em)을 걸어서 작은 글자가 더 빽빽하다. (`index.css`, `packages/ui` 여러 곳)
2. **새로 고침하면 빈 흰 화면.** `index.html`에 아무것도 없다. 번들을 받고 첫 데이터가 올 때까지 약 1.5초 동안 아무것도 보이지 않는다.
3. **랜드마크.** `<main>`이 두 번 겹쳐 있다(`__root`/`p.$projectId.tsx`와 `Page`). 숨겨 둔 검색 패널의 글을 스크린 리더가 읽는다.
4. **채팅 패널.**
   - 답이 `text-sm`, 줄간격 relaxed, 폭 380px이라 빽빽하다. 도구 카드는 `text-xs`이고 카드 제목이 줄바꿈된다.
   - 대화 제목이 첫 메시지를 그대로 되풀이한다(헤더와 첫 말풍선에 같은 문장이 나온다).
5. **정보 구조.**
   - 에이전트 설정이 **AI › 사용 방식** 안에 묻혀 있다(도구 표, 기본 권한 모드). '에이전트' 화면이 없다.
   - 용어집이 **문맥 › 용어집** 아래 4번째 탭이다.
   - 설정은 '프로젝트'와 '상태·태그' 두 개뿐이고, 섹션마다 저장 버튼이 따로 있으며, 위험 구역(프로젝트 삭제)이 분리돼 있지 않다.

**P2**

6. **탭 스타일이 두 가지다.** 상단 밑줄 탭과, 실행 상세·인물·관계의 상자형 세그먼트가 섞여 있다.
7. **상단 바 아이콘 버튼에 이름이 보이지 않는다.** 검색 옆의 대사 패널·채팅 버튼은 툴팁으로만 알 수 있다.
8. **대사 편집기.**
   - 미번역 줄에 `미번역`이 두 번 나온다(상태 점과 '— 미번역').
   - 모든 줄에 주황 `→ 청자 미상`이 붙어서 경고가 소음이 된다.
   - 화자 이름은 대문자 12px이다.
   - 서식 칩(`⟨1breaker panel1⟩`)은 번호와 글자가 붙어 보인다.
9. **목록의 라벨과 값이 붙어 보인다.** 예: `워크플로기본 번역v3`, `성공모델 1개`.
10. **사이드바가 패키지 밖에 있다.** `apps/web/src/components/ui/sidebar.tsx`(724줄)와 `app-sidebar.tsx`. 활성 항목은 회색 배경으로만 표시된다.

**P3**

11. 워크플로 노드의 `border-l-4` 강조(detector가 찾음).
12. 노드 설정 패널이 너무 길다(구획 없이 위에서 아래로 나열된다).

## 원칙 (Operate 모드)

- **글꼴:** Pretendard 한 가지. 크기는 고정된 rem 단계로, 단계 사이 비율은 약 1.15를 쓴다.
- **글자 역할:**
  - 보조 12px(`text-xs`): 날짜, 개수, 도움말, 열 머리글
  - 본문 13px(`text-sm`): 표의 행, 채팅 답, 폼 값. 새로 정한다
  - 강조 본문 14px(`text-base`)
  - 제목 16px(`text-lg`)
  - 페이지 제목 18px(`text-xl`)
  - 배지 11px(`text-2xs`)가 최소이고, 10px은 쓰지 않는다
- **자간:** 음수 자간은 14px 이상 제목에만 쓴다. 12–13px은 0으로 둔다.
- **색:** 지금의 Restrained 방식을 유지한다. 보조 글자 대비는 4.5:1 이상으로 올린다.
- **탭:** 한 가지 방식만 쓴다(밑줄 탭). 상자형 세그먼트는 '표시 방식 전환'(그래프/표)에만 쓴다.
- **아이콘 버튼:** 모든 아이콘 버튼은 `aria-label`과 툴팁이 같은 이름을 갖는다.

## 계획 (집중 PR)

1. **토큰·글자**
   - `@loca/ui`에 글자 역할 토큰(`--text-2xs…xl`)을 두고, 자간 규칙을 정한다.
   - `ui-rules`를 패키지까지 넓히고 `text-[Npx]`를 쓰지 못하게 한다.
   - `index.html`에 정적 로딩 화면을 넣는다.
2. **내비게이션·정보 구조**
   - 새 메뉴 '에이전트': 도구, 기본 권한 모드, 자동 검토.
   - 용어집은 번역 작업의 짝이라 '번역' 아래로 옮긴다(대사·그래프·용어집).
   - '문맥'은 '자료'로 부른다(문서·인물·관계·사건).
   - 설정 정리, 아이콘 버튼 이름, 탭 한 가지, `<main>` 하나.
3. **사이드바를 `@loca/ui`로**
   - `sidebar.tsx`(724줄)를 패키지로 옮기고, 앱의 중계 파일과 `@/components/ui` import를 정리한다.
   - 활성 항목은 강조색 막대 대신 진한 글자와 배경으로 표시한다.
4. **채팅 패널**
   - 본문 14px, 줄간격과 여백을 조정하고 도구 카드를 단순하게 만든다.
   - 제목은 첫 메시지를 짧게 줄인 것으로 하고 헤더에서 되풀이하지 않는다.
   - 좁은 폭에서 카드 제목이 줄바꿈되지 않게 한다.
5. **편집기(대사)**
   - 미번역은 한 번만 표시한다.
   - 청자 미상은 조용한 표시로 바꾸고, 가리키면 강조한다.
   - 화자 이름을 읽기 쉽게, 서식 칩에 여백을 준다.
6. **설정**
   - 페이지마다 저장 막대 하나로 통일한다.
   - 위험 구역(프로젝트 삭제)을 분리한다.
   - 설정 폼 레이아웃은 `@loca/ui`의 `SettingsSection`으로 만든다.

PR마다 1280과 1500에서 개선 전후 스크린숏을 남긴다(`/workspace/loca-review/batch5/after/`).
