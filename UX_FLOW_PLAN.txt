  장면 사각형·조건 마름모·대기 모래시계·이벤트 원·상태 육각형·합류 점을 사용.
- 보존: 프로젝트·범위·검색/필터·선택·Canvas viewport·읽기 스크롤/초안.

U2. 프로젝트 채팅에서 조사

- 보존: 세션별 대화·입력·첨부·웹 설정. 새 세션은 별도 대화, 저장 자료는 공유.
  프로젝트 전환과 Back/Forward 뒤에도 다른 작품의 대상/제안이 섞이지 않음.
- 복구: 연결/검색 실패와 한도 도달은 실제 도구 상태로 표시하고 재질문 가능.
- 증거: 모의 도구 호출 로그와 세션/프로젝트 왕복. 전체 원문을 무조건 전송하지 않음.

2026-10-09 Orwell 2 번역 준비 및 작업별 fallback

  fallback에서 사용 중이면 막는다. 미설정은 자동 전환 없음이다.

1. 프로젝트 목록·자동 보관·열기, 원문 갱신과 백업 복원/결과 내보내기 분리.

원본 게임 폴더와 기존 main 작업 DB에서 모델 실행/번역 수정은 하지 않는다.

2026-10-09 U5 상태·라벨 실행 범위 필터
- 프로세스 화면에서 장면/선택 ID/전체 범위를 고른 뒤 같은 실행 영역의
  상태·라벨 필터를 적용한다. 상태 여러 개는 하나 이상(OR), 라벨 여러 개는
  모두(AND)로 판정하며 선택이 없으면 해당 조건을 제한하지 않는다.
- 대상 수는 선택 범위와 필터의 교집합이다. 대상 미리보기, 모의 시험, 실행은
  같은 원문 ID 집합을 사용한다. 존재하지 않는 ID/필터는 표시하고 시작을 막는다.
  0개에서는 시험/실행을 하지 않는다. 서버도 현재 대상/필터를 다시 검사한다.
- 필터와 선택 범위는 프로젝트/작업 공간별로 초안과 함께 보존한다.
  다른 화면·Back/Forward·새로고침·polling이 필터나 편집 초안을 초기화하지 않는다.
  선택 장면/대사에서 진입해도 기존 프로세스 초안은 지우거나 자동 실행하지 않는다.
- 수용: 합성 자료에서 상태 OR + 라벨 AND, 장면/ID/전체의 교집합, 빈 결과,
  잘못된 ID, 현재 상태 변경, 시험/실행 동일 선택을 자동 검사한다.
  브라우저 확인은 root의 격리 fixture에서 수행하며 사용자 DB/실제 AI를 쓰지 않는다.

2026-10-09 U5 실행 스냅샷과 편집 흐름 구분

- 실행 흐름은 run.definition 스냅샷을 읽기 전용 Canvas로 표시한다. 노드 선택은

  스냅샷과 일치하는지, 편집 복귀 시 초안/위치가 유지되는지 격리 fixture에서 확인한다.
U11 프로필 이식: AI 설정의 저장된 프로필 선택→복제로 새 ID 초안 생성, 또는 선택 프로필 JSON 내보내기→다른 프로젝트 프로필 목록의 JSON 가져오기→연결 참조가 없는 경로는 연결 선택을 요구→이름/모델/지시문/도구·맥락 정책 검토→명시적으로 저장. 가져오기만으로 저장·시험·모델 실행하지 않는다. 파일은 형식·버전·허용 필드를 검사하고 연결 설정/키/원문 대상/세션/실행 기록을 담지 않는다. 초안은 기존 편집 캐시로 탐색·새로고침에 유지한다. 수용: 알 수 없는 필드/프로토타입/인증 필드 거부, 대체 경로도 미연결이면 저장 금지, 복제는 저장본 기준, JSON 왕복 정책 보존, 프로젝트 이동 시 임의 연결 자동 선택 없음.

2026-10-09 U12 전역 채팅 사이드 패널 — 구현 전 사용자 여정

  좁은 화면에서는 본문 일부를 가리는 패널이지만 닫기와 본문 접근을 유지한다.

- 그래프의 선택 원문으로 채팅하기는 화면을 떠나지 않고 패널을 열어 현재 세션에

  기존 view=chat 주소는 작품 화면 + 열린 채팅으로 정규화하고 resource는 세션에 옮긴다.
